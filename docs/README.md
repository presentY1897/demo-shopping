# 문서 체계

| 디렉터리 | 목적 |
| --- | --- |
| `tasks/` | 개발 작업 계획서. **승인 후 구현**이 원칙. |
| `decisions/` | 세션(대화)에서 정해진 사항의 누적 이력. |

## 진행 흐름

```
아이디어 → docs/tasks/TASK-NNN-*.md 작성 → 사용자 검토/승인 → 구현 → 문서 상태 갱신
                                              ↘ 논의 중 정해진 사항 → docs/decisions/ 기록
```

## 규칙

- Task 번호는 `TASK-001` 부터 순차 증가. 재사용하지 않는다.
- 결정 이력은 세션 단위로 파일을 나누고, 기존 파일은 수정하지 않고 추가한다.
  (결정이 번복되면 새 항목에 "이전 결정 대체" 로 명시한다.)
