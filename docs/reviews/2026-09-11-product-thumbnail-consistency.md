# 상품 썸네일 처리 누락 검토

장바구니·주문서·주문 상세는 ProductThumbnail을 사용한다. 이 컴포넌트는 기존 시드 CDN의 알려진 hash를 동일 바이트 로컬 자산으로 보정하고, null/빈 주소와 로딩 실패는 대체 아이콘으로 표시한다. 최근 본 상품 스트립/전체 목록·찜 목록은 thumbnailUrl을 img에 그대로 넣어 이 처리를 우회했다. 화면별로 저장소가 다른 것이 아니라 공통 표시 컴포넌트 적용 누락이 직접 원인이다.

세 화면에서 개별 img를 ProductThumbnail로 교체했다. 브라우저 저장 이력, API 응답, 주문 스냅샷, DB와 CDN 객체는 변경하지 않았다. 검색 카드와 갤러리는 기존 productImageUrl 사용을 확인했으며 리뷰 사진/스토어 로고는 상품 썸네일과 구분했다.

회귀5개는 수정 전 실패하고 수정 후 통과했다. 로그인/비로그인 최근 본 스트립/전체 목록, 로그인 찜 목록에서 URL 보정과 error 후 img 제거를 검증한다. 공통 컴포넌트·URL resolver를 포함해42개 검사 통과.

로컬 Next 브라우저390px에서 홈/최근 본(비로그인 및 로그인)과 찜(로그인), 총5개 경로의 실제 SVG 디코딩을 확인했다. API는 계약 형태 대역이며 이미지 요청은 실제 로컬 파일이다. 비로그인 localStorage 원본 URL/내용 유지도 확인했다. 운영 배포 결과를 의미하지 않는다.

구매자 앱 전체 검사 결과: typecheck/lint/build 성공, 테스트1,275개 통과·기존 skip1개. 변경 파일 eslint/prettier 및 git diff --check 통과. 로컬 구현/검증 커밋을 전용 브랜치에 남겼으며 PR/운영 배포는 아직 진행하지 않았다.
