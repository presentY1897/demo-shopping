# M11. 할인 (쿠폰 · 적립금)

M07 에서 만든 금액 계산 엔진의 `discounts` 목록에 쿠폰과 적립금을 꽂는다. 주문 로직을 다시 만들지 않는다. (D-036)

**부담 주체를 반드시 기록**한다. 플랫폼 쿠폰·적립금은 플랫폼 부담, 판매자 쿠폰만 정산에서 차감한다. 이 구분이 없으면 정산이 단순 곱셈이 된다. (D-029)

**완료 조건**: 쿠폰과 적립금을 함께 쓴 주문을 부분 취소해도 각각 정확히 되돌아간다.
