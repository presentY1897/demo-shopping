## 1. 목적

판매자가 자기 부담 쿠폰을 발행하는 화면을 만든다. **정산에서 차감된다는 사실을 명확히 보여준다.**

## 2. 범위

### 포함
- 쿠폰 목록·발행 (범위는 자기 상품·자기 스토어로 제한)
- **판매자 부담 명시** — "정산 시 차감됩니다" 경고
- 예상 부담액 표시
- 발행 중단
- 쿠폰별 사용 현황·부담액 누계
- 정산 화면과 연결 (M12)

### 제외
- 플랫폼 쿠폰 (TASK-0073)

## 3. 요구사항

- [ ] 판매자는 자기 상품 범위 쿠폰만 발행할 수 있다
- [ ] 정산에서 차감된다는 안내가 명확히 표시된다
- [ ] 지금까지의 부담액 누계를 볼 수 있다
- [ ] 발행 중단이 가능하다

## 4. 설계

발행 폼 상단에 경고를 배치한다.

```
⚠ 이 쿠폰의 할인액은 판매자 정산에서 차감됩니다.
   예상 최대 부담: 100장 × 5,000원 = 500,000원
```

**판매자가 부담 구조를 모르고 쿠폰을 뿌리는 상황**이 실제로 흔하다. 발행 전에 숫자로 보여준다. D-029 의 부담 주체 구분이 사용자에게 드러나는 지점이다.

## 5. 구현 계획

1. 목록 화면
2. 발행 폼 (범위 제한 + 부담 경고 + 예상액)
3. 발행 중단
4. 사용 현황·부담액 누계
5. 정산 연결 자리
