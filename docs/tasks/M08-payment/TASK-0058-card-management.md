# TASK-0058: 가상 카드 관리 화면

| 항목 | 내용 |
| --- | --- |
| 마일스톤 | M08 결제 |
| 상태 | 승인됨 |
| 작성일 | 2026-09-02 |
| 브랜치 | `feature/card-management` |
| 선행 작업 | TASK-0053 |

## 1. 목적

마이페이지에서 가상 카드를 발급·조회하는 화면을 만든다. **환불이 잘 됐는지 잔액으로 확인**할 수 있게 한다.

## 2. 범위

### 포함
- 카드 목록 (번호 마스킹, 한도, 사용액, 사용 가능액)
- 카드 발급 (한도 지정)
- 카드별 사용 내역 (원장 조회)
- 카드 정지·해제
- 결제 화면의 카드 선택 UI
- "가상 카드" 안내 문구 — 실제 결제가 아님을 명시
- 데모 계정에 지급된 카드 표시

### 제외
- 실제 카드 등록 (구현하지 않음)

## 3. 요구사항

- [ ] 카드 목록에서 한도와 사용 가능액이 보인다
- [ ] 결제 후 사용 내역이 즉시 반영된다
- [ ] 환불하면 잔액이 복구되는 것이 보인다
- [ ] 카드번호가 마스킹되어 표시된다
- [ ] 가상 카드임이 명확히 안내된다

## 4. 설계

```
9999-****-****-1234    한도 1,000,000원
                       사용 189,000원 / 잔여 811,000원
                       [사용 내역] [정지]
```

사용 내역은 승인·취소·환불을 시간순으로 보여준다. 주문 링크를 함께 걸어 **"이 결제가 이 주문"**임을 연결한다. 환불 확인 동선이 여기서 완성된다.

### 4.1 「3장 해당 없음」이 아니다 — 사용 내역 라우트가 없다 (2026-09-05 정정)

6.2 가 「API 는 TASK-0053」이라고 적었는데, 0053 이 만든 것은 **발급·목록·정지·삭제**
까지다. F3 이 요구하는 **사용 내역**(카드 원장 조회)은 어디에도 없다.

그래서 라우트 하나를 더한다.

```
GET /api/v1/cards/:id/transactions
```

**3장은 A2~A5 가 적용된다.** 새 라우트가 생겼으므로 남의 카드 원장을 읽는 것이
표현 가능해졌고, 그것을 막는 것이 A3 다. 4장은 그대로 해당 없다 — 스키마는 0053 이
이미 만들었다.

### 4.2 「이 결제가 이 주문」을 잇는 것은 **원장이 아니라 결제**다

4장이 「주문 링크를 함께 걸어」라고 적었는데, 카드 원장 행이 들고 있는 것은
`refId` = **결제 id** 다. 주문 id 가 아니다.

그 사이를 잇는 것은 `Payment.orderId` 이고, 그래서 사용 내역 응답이 주문번호를 함께
싣는다 — 화면이 결제 id 로 다시 물어보게 두면 줄마다 왕복이 하나씩 붙는다.

**주문이 없는 행도 있다.** 카드는 결제 말고도 쓸 수 있게 만들어 두었고(원장의
`refId` 는 무엇이든 될 수 있다), 그때 주문번호는 `null` 이다 — 링크가 없는 줄이지
잘못된 줄이 아니다.

### 4.3 결제 화면의 카드 선택은 **이미 있다**

2장의 범위에 「결제 화면의 카드 선택 UI」가 적혀 있는데 TASK-0054 가 그것을 만들었다.
주문서에서 카드를 고르고 결제하는 흐름이 이미 돌아간다.

여기서 하는 일은 **관리 쪽**이다 — 발급하고, 잔액을 보고, 사용 내역으로 「환불이
정말 돌아왔나」를 확인하는 것. 그 확인 동선이 이 화면의 존재 이유다.

### 4.4 이 TASK 는 M08 의 마지막이 아니다 (D1 정정)

D1 이 「M08 마일스톤 완료 처리」라고 적었는데, 번호만 보면 마지막이지 의존 관계로는
아니다. 남는 것이 셋이다 — TASK-0055(토스) · 0056(웹훅) · 0057(실패 복구).

그리고 **0055 는 사용자 액션 대기**다. 토스 개발자센터 테스트 키가 없으면 시작할 수
없고, `OWNER-CHECKLIST` 8번이 이미 「가입에 사업자 정보가 필요하면 토스만 보류하고
진행할 수 있다」고 적어 두었다 — 가상 카드만으로 전체 흐름이 완결되기 때문이다(D-031).

마일스톤을 닫는 것은 **마지막으로 끝나는 TASK** 의 일이다.

2. 발급 폼 (한도 지정)
