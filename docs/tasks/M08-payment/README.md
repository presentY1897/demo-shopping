# M08. 결제

**가상 카드(자체) + 토스페이먼츠(테스트)** 두 프로바이더를 하나의 인터페이스 뒤에 둔다. 프로바이더가 둘이어야 추상화가 장식이 아닌 실제 설계가 된다. (D-031)

가상 카드는 **한도 초과·잔액 부족·승인 거절·지연을 의도적으로 재현**한다. 결제 실패 시 재고 예약이 제대로 해제되는지 시연하기 위한 장치다.

**완료 조건**: 두 결제수단으로 주문이 완료되고, 실패 시나리오에서 재고와 주문 상태가 정확히 되돌아간다.
