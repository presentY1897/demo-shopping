# M04. 인증 · 계정

Google 로그인, 앱별 독립 세션, 데모 계정 발급·만료를 구현한다. 이후 모든 마일스톤이 "누가 요청했는가"를 전제로 동작한다.

**완료 조건**: 세 앱에서 각각 Google 로그인과 데모 발급이 되고, 권한 없는 경로 접근이 차단되며, 만료된 데모 계정이 자동 정리된다.

> **선행 정정 (2026-09-03)** — TASK-0020 의 선행은 M03 가 아니라 **M01** 이다. 스키마 정의에 디자인 시스템이 필요하지 않으며, 필요한 것은 M01 이 세운 Prisma 마이그레이션 파이프라인뿐이다. 화면이 필요한 TASK-0023 부터 M03 의 컴포넌트에 의존한다.
