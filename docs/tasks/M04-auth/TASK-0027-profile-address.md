## 1. 목적

마이페이지의 프로필과 배송지 관리를 만든다. 배송지는 주문서(M07)에서 그대로 쓰인다.

## 2. 범위

### 포함
- 프로필 조회·수정 (이름, 연락처, 아바타)
- 사용자 설정 (밀도, 알림 수신 여부) — 밀도는 서버 저장으로 승격
- 배송지 CRUD, 기본 배송지 지정
- 주소 입력 (우편번호 검색 연동)
- 회원 탈퇴 (소프트 삭제)
- 판매자 스토어 설정 (브랜드명·소개·로고 수정)

### 제외
- 주문서에서의 배송지 선택 UI (M07)
- 알림 실제 발송 (M13)

## 3. 요구사항

- [ ] 프로필을 수정하면 즉시 반영된다
- [ ] 배송지를 여러 개 저장하고 기본을 지정할 수 있다
- [ ] 기본 배송지는 항상 1개다
- [ ] 밀도 설정이 서버에 저장되어 다른 기기에서도 유지된다
- [ ] 탈퇴 후에도 과거 주문 이력이 보존된다

## 4. 설계

**밀도 설정의 저장 위치**: 비로그인은 localStorage, 로그인은 `UserPreference`. 로그인 시 localStorage 값을 서버로 승격하고 이후 서버 값을 따른다.

우편번호 검색은 외부 위젯(예: 다음 우편번호)을 사용한다. 주소 정규화는 하지 않는다.

## 5. 구현 계획

1. 프로필 조회·수정 API + 화면
2. 사용자 설정 API + 밀도 승격 로직
3. 배송지 CRUD API
4. 배송지 관리 화면 + 우편번호 검색
5. 기본 배송지 전환 (트랜잭션)
6. 탈퇴 처리
7. 판매자 스토어 설정 화면
