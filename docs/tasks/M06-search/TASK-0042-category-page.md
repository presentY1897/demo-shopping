## 1. 목적

카테고리 탐색 경로를 만든다. 검색 페이지와 같은 필터·목록을 쓰되 진입 맥락이 다르다.

## 2. 범위

### 포함
- `/categories/[slug]` — 하위 카테고리 전체 상품
- 카테고리 네비게이션 (헤더 메가메뉴 또는 드롭다운)
- 브레드크럼
- 하위 카테고리 바로가기
- 필터·정렬·목록 (TASK-0041 컴포넌트 재사용)
- SEO — 메타 태그, 구조화 데이터
- 존재하지 않는 slug 404

### 제외
- 카테고리별 배너·큐레이션

## 3. 요구사항

- [ ] 상위 카테고리에서 하위 상품이 모두 보인다
- [ ] 브레드크럼으로 상위로 이동할 수 있다
- [ ] 검색 페이지와 동일한 필터 동작을 한다
- [ ] 비활성 카테고리는 접근되지 않는다

## 4. 설계

카테고리 페이지는 **검색 API 에 `categoryId` 를 고정한 것**이다. 별도 API 를 만들지 않는다. `path` 기반 하위 포함 조회를 검색 필터로 표현한다.

## 5. 구현 계획

1. 카테고리 라우트 + 데이터 로딩
2. 브레드크럼·하위 바로가기
3. 헤더 카테고리 네비게이션
4. 필터·목록 재사용 연결
5. SEO 메타·구조화 데이터
6. 404·비활성 처리
