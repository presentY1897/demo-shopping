## 1. 목적

배송 전 취소를 구현한다. 부분 취소를 포함하고, 취소된 만큼 결제가 부분 환불된다.

## 2. 범위

### 포함
- 구매자 취소 신청 화면 (항목·수량 선택, 사유 입력)
- 신청 → 승인 → 환불 → 완료 흐름
- **결제완료(PAID) 상태는 자동 승인** — 판매자가 아직 준비 안 함
- 상품준비중(PREPARING)은 판매자 승인 필요
- 취소 완료 시 재고 복원 트리거 (TASK-0069)
- 환불 실행 트리거 (TASK-0068)
- 전체 취소 시 SellerOrder CANCELED 전환
- 부분 취소 시 남은 항목 기준 상태 유지
- 취소 불가 안내 (이미 발송 등)

### 제외
- 반품 (TASK-0067)
- 환불 계산 로직 자체 (TASK-0068)

## 3. 요구사항

- [ ] 항목·수량을 골라 취소할 수 있다
- [ ] 결제완료 상태의 취소는 즉시 처리된다
- [ ] 준비중 상태는 판매자 승인 후 처리된다
- [ ] 전체 취소하면 주문 묶음이 취소 상태가 된다
- [ ] 부분 취소 후 남은 항목은 계속 진행된다

## 4. 설계

```
PAID       → 취소 신청 → 자동 승인 → 환불 → 재고 복원 → 완료
PREPARING  → 취소 신청 → 판매자 승인/거절 → (승인 시) 환불 → 재고 복원 → 완료
```

**결제완료 상태를 자동 승인하는 이유**: 판매자가 아직 아무것도 하지 않았다. 승인을 기다리게 하면 구매자가 불필요하게 대기하고, 판매자에게도 의미 없는 업무가 생긴다.

판매자가 이미 발송했는데 취소 요청이 들어오면 **거절 후 반품으로 안내**한다.

## 5. 구현 계획

1. 취소 신청 API + 화면
2. 자동 승인 분기
3. 판매자 승인·거절
4. 환불·재고 복원 연동
5. SellerOrder 상태 판단 (전체/부분)
6. 취소 불가 안내
7. 통합 테스트
