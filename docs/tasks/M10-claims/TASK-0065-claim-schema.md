## 1. 목적

취소와 반품을 하나의 클레임 모델로 다룬다. **항목·수량 단위 신청**을 스키마가 지원하게 한다.

## 2. 범위

### 포함
- `ClaimRequest` — SellerOrder, 유형(CANCEL/RETURN), 상태, 사유, 귀책(고객/판매자), 신청자
- `ClaimItem` — 대상 OrderItem, 수량, 계산된 환불액
- 클레임 상태 머신 (취소 경로 / 반품 경로)
- 신청 가능 여부 판정 — 주문 상태·기간·이미 신청된 수량 확인
- 상태 이력 기록
- 항목별 잔여 신청 가능 수량 계산

### 제외
- 실제 취소·반품 처리 (TASK-0066, 0067)
- 환불 실행 (TASK-0068)

## 3. 요구사항

- [ ] 주문 항목 3개 중 1개만, 그 중 일부 수량만 신청할 수 있다
- [ ] 이미 신청한 수량만큼은 다시 신청할 수 없다
- [ ] 주문 상태에 따라 취소·반품 경로가 자동으로 갈린다
- [ ] 정의되지 않은 상태 전이는 거부된다
- [ ] 구매확정 후에는 일반 반품이 불가능하다

## 4. 설계

상태 정의는 `docs/design/state-machines.md` 4장을 따른다.

| 주문 상태 | 가능한 클레임 |
| --- | --- |
| PAID / PREPARING | 취소 |
| SHIPPED | 취소 불가 (배송중), 도착 후 반품 |
| DELIVERED | 반품 (기간 내) |
| CONFIRMED | 일반 반품 불가, 관리자 개입만 |

```
잔여 신청 가능 수량 = OrderItem.quantity − 이미 신청·처리된 수량 합계
```

**항목 단위로 설계하는 이유**: 주문 항목 3개 중 1개만 취소하는 건 정상 흐름이다. 주문 단위로만 만들면 실제 서비스로 쓸 수 없다.
