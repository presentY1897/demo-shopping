## 1. 목적

판매자가 취소·반품 요청을 처리하는 화면을 만든다.

## 2. 범위

### 포함
- 클레임 목록 (유형·상태 탭, 처리 대기 우선)
- 클레임 상세 (대상 항목·수량·사유·첨부 사진·환불 예정액)
- 승인·거절 (거절 사유 필수)
- 수거 처리, 입고 검수 (합격·불합격)
- 귀책 판단 입력
- 처리 대기 건수 뱃지·대시보드 연동
- 처리 기한 표시 (지연 경고)

### 제외
- 관리자 개입 (TASK-0071)

## 3. 요구사항

- [ ] 처리 대기 클레임이 먼저 보인다
- [ ] 환불 예정액이 처리 전에 표시된다
- [ ] 거절 시 사유를 반드시 입력해야 한다
- [ ] 검수 결과에 따라 환불 여부가 갈린다
- [ ] 지연된 클레임이 강조된다

## 4. 설계

**환불 예정액을 미리 보여주는 이유**: 판매자가 승인 버튼을 누르기 전에 얼마가 나가는지 알아야 한다. 배송비 부담, 쿠폰 안분까지 반영된 실제 금액을 표시한다.

처리 기한: 신청 후 2영업일. 초과하면 목록에서 강조하고 관리자 대시보드에도 노출한다.

## 5. 구현 계획

1. 목록 API·화면 (탭·정렬)
2. 상세 화면 + 환불 예정액 계산 표시
3. 승인·거절 처리
4. 수거·검수 처리
5. 귀책 판단 입력
6. 뱃지·기한 경고
