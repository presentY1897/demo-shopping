# M10. 취소 · 반품 · 환불

**부분 취소·부분 반품**과 환불 안분을 구현한다. 결제 1건에 부분 환불이 여러 번 발생하는 구조라 이 프로젝트에서 기술적으로 가장 까다로운 부분이다. (D-027)

교환은 구현하지 않는다. 반품 후 재구매로 안내한다.

**완료 조건**: 주문 항목 3개 중 1개만 취소·반품해도 금액·재고·정산이 정확히 맞는다.
