# M14. 관리자

앞선 마일스톤에서 필요에 따라 만든 관리자 화면들을 완성하고, 아직 없는 운영 기능을 채운다.

**완료 조건**: 관리자가 회원·판매자·상품·주문을 조회·관리할 수 있고, 데모 계정 현황을 확인할 수 있다.

**✅ 충족.** 다섯 화면이 다 서고, 그중 절반은 **이미 있던 것을 다시 만들지 않은 결과**다 — 승인·정지는 M04, 수수료율은 M12, 전체 상품 목록은 M05, 역할 부여는 M04, 데모 정리는 M04 에 있었다. 착수 전에 기준표 36개를 코드에 대고 세어 본 덕분이고, 안 세었으면 같은 일을 하는 문이 둘이 됐을 것이다 (D-256).

닫기 전에 한 번 더 읽은 것이 값을 했다. **데모 관리에서 결함 셋이 나왔다** — 정리 실패 칸을 아무도 쓰지 않아 화면이 늘 「정상」이라 말했고, 정책 행을 아무도 읽지 않아 수명이 여전히 상수였으며, 처리 건수는 어디에도 없었다. 셋 다 화면과 서버가 각자 green 인 채로 조용했다 (D-249 가 M13 에서 배운 그대로다).
