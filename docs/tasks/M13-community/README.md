# M13. 회원 부가 기능

리뷰·위시리스트·최근 본 상품·알림·Q&A·팔로우를 만든다. (D-030)

리뷰는 `orderItemId` unique 로 **구매 검증을 스키마가 강제**한다. 구매하지 않은 사람은 행을 만들 수 없고 중복 리뷰도 DB 가 막는다.

**완료 조건**: 구매한 상품에만 리뷰를 쓸 수 있고, 주문 상태가 바뀌면 알림이 도착한다.

**✅ 충족.** 앞의 절반은 서비스가 아니라 **스키마**가 지킨다 — 리뷰는 주문 항목을 가리켜야 하고 그 항목의 상품과 리뷰의 상품이 복합 외래키로 묶여 있어, 사지 않은 상품의 리뷰는 **가리킬 행이 없다** (`review.spec.ts` 「중복은 DB 가 막는다 — 코드를 지나지 않아도」 · 「주문 항목과 다른 상품을 가리키는 리뷰는 저장되지 않는다」). 검사에는 우회 경로가 생겨도 없는 행은 어떤 경로로도 만들 수 없다 (D-238).

뒤의 절반은 `notification.spec.ts` 「발송 처리하면 구매자에게 알림이 온다」가 끝에서 끝까지 걸어 확인한다. 그 알림은 **원래 작업을 절대 실패시키지 않는다** — 알림 생성이 터져도 발송 처리는 끝난다 (D-242). 재고를 고쳤는데 저장이 안 되는 것이 알림을 못 받는 것보다 나쁘기 때문이다.
