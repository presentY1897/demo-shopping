## 1. 목적

브랜드 팔로우를 만든다. 신상품 알림의 근거가 된다.

## 2. 범위

### 포함
- `SellerFollow` — 사용자, 판매자 (unique)
- 팔로우·언팔로우 토글
- 브랜드관·상품 상세의 팔로우 버튼
- 팔로우 목록 페이지
- 판매자 팔로워 수 표시
- **신상품 등록 시 팔로워 알림** (TASK-0090 연동)
- 홈의 팔로우 브랜드 신상품 섹션

### 제외
- 팔로워 목록 공개

## 3. 요구사항

- [ ] 팔로우 상태가 즉시 반영되고 유지된다
- [ ] 팔로우한 브랜드의 신상품 알림이 온다
- [ ] 판매자가 자기 팔로워 수를 볼 수 있다
- [ ] 홈에서 팔로우 브랜드 신상품이 보인다

## 4. 설계

팔로워 수는 **카운트 컬럼으로 캐시**한다. 매번 집계하면 브랜드관 로딩이 느려진다.

신상품 알림은 팔로워가 많으면 알림이 대량 생성된다. 배치로 나눠 발행하고, 상품 등록 트랜잭션과 분리한다.

## 5. 구현 계획

1. 스키마·마이그레이션
2. 토글 API + 카운트 갱신
3. 팔로우 버튼 컴포넌트
4. 팔로우 목록 페이지
5. 신상품 알림 이벤트 (배치 발행)
6. 홈 섹션
