## 1. 목적

찜 기능을 만든다. 목록·상세의 찜 버튼이 실제로 동작하게 한다.

## 2. 범위

### 포함
- `Wishlist` — 사용자, 상품, 담은 시각
- 담기·해제 API (토글)
- 위시리스트 페이지 (목록 그리드 재사용)
- 상품 카드·상세의 찜 버튼 연동
- 비로그인 시 로그인 유도
- 품절·가격 변동 표시
- **재입고 알림 신청** (TASK-0090 연동)
- 위시리스트에서 장바구니로 이동

### 제외
- 폴더·컬렉션 분류

## 3. 요구사항

- [ ] 찜 버튼이 즉시 반영된다 (낙관적 업데이트)
- [ ] 새로고침해도 상태가 유지된다
- [ ] 품절 상품에 재입고 알림을 신청할 수 있다
- [ ] 비로그인 시 로그인으로 유도된다

## 4. 설계

찜 버튼은 **낙관적 업데이트**로 처리한다. 서버 응답을 기다리면 반응이 느리게 느껴진다. 실패 시 되돌리고 토스트로 알린다.

**재입고 알림을 위시리스트에 붙이는 이유**: 품절이라 못 산 상품이 위시리스트에 쌓인다. 여기가 재입고 알림의 가장 자연스러운 진입점이다.

## 5. 구현 계획

1. 스키마·마이그레이션
2. 토글 API
3. 찜 버튼 컴포넌트 (낙관적 업데이트)
4. 위시리스트 페이지
5. 품절·가격 변동 표시
6. 재입고 알림 신청
7. 장바구니 이동
