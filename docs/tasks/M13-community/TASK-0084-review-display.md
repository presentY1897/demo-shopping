## 1. 목적

상품 상세에 리뷰를 표시하고 평점을 집계한다. 밀도 3단계에 따라 노출량이 달라진다.

## 2. 범위

### 포함
- 상품별 리뷰 목록 (정렬: 최신·평점·도움순, 커서 페이지네이션)
- 평점 분포 (별점별 개수·비율)
- `Product.ratingAvg` / `ratingCount` 집계 갱신
- 밀도별 노출량 — 미니멀은 링크만, 표준 3건, 맥시멀 5건 + 분포
- 사진 리뷰 필터·갤러리
- 도움돼요 투표
- 검색 인덱스의 `ratingAvg` 갱신 연동
- 리뷰 신고 버튼 (TASK-0091 연결)

### 제외
- 판매자 답변 (TASK-0085)
- 신고 처리 (TASK-0091)

## 3. 요구사항

- [ ] 상품 상세에서 리뷰와 평점 분포를 볼 수 있다
- [ ] 평점 평균이 리뷰 작성·삭제에 따라 갱신된다
- [ ] 검색 정렬(평점순)에 반영된다
- [ ] 밀도 단계별로 노출량이 다르다

## 4. 설계

집계는 **리뷰 작성·수정·삭제 시 갱신**한다. 조회할 때마다 집계하면 상품 목록에서 N+1 이 된다.

```
리뷰 변경 → Product.ratingAvg/ratingCount 갱신 → 검색 인덱스 이벤트 발행
```

밀도별 노출:

| | 미니멀 | 표준 | 맥시멀 |
| --- | --- | --- | --- |
| 평점 | 숫자만 | 별점 + 개수 | 별점 + 분포 그래프 |
| 리뷰 | 링크만 | 3건 | 5건 + 사진 갤러리 |

## 5. 구현 계획

1. 리뷰 목록 API (정렬·커서)
2. 평점 집계·갱신
3. 검색 인덱스 연동
4. 상품 상세 리뷰 섹션 (밀도 분기)
5. 사진 갤러리·필터
6. 도움돼요 투표
7. 성능 확인
