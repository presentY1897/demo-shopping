## 1. 목적

판매자가 자기 상품을 관리하는 화면을 만든다. 재고 수정이 원장을 거치도록 강제한다.

## 2. 범위

### 포함
- 상품 목록 (상태·카테고리·재고 필터, 검색)
- 일괄 상태 변경 (판매중지·재개)
- Variant 재고 인라인 수정 → **재고 원장 기록**(TASK-0036)
- 품절 임박 표시
- 상품 복제
- 커서 페이지네이션

### 제외
- 원장 자체 구현 (TASK-0036)
- 주문 관리 (M09)

## 3. 요구사항

- [ ] 자기 상품만 보인다
- [ ] 재고 수정이 원장에 기록된다
- [ ] 품절·품절 임박 상품을 필터로 찾을 수 있다
- [ ] 일괄 상태 변경이 동작한다

## 4. 설계

재고 수정은 **절대값 입력이 아니라 조정량 입력**으로 받는다. 절대값을 받으면 동시에 판매가 일어났을 때 덮어써서 재고가 틀어진다.

```
현재 12개 → "+5 입고" → 원장에 +5 기록 → 결과 17
```

## 5. 구현 계획

1. 목록 API (필터·검색·커서)
2. 목록 화면
3. 재고 조정 UI + 원장 연동
4. 일괄 상태 변경
5. 품절 임박 기준 정의 및 표시
6. 상품 복제
