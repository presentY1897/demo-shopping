## 1. 목적

판매자가 상품을 등록하는 화면을 만든다. **카테고리를 고르면 속성 입력 폼이 자동 생성**되는 것이 이 화면의 핵심이다.

## 2. 범위

### 포함
- 기본 정보 (이름, 설명, 카테고리)
- **카테고리 선택 시 속성 폼 자동 생성** (TASK-0017 동적 폼 + TASK-0030 정의)
- 이미지 업로드 (TASK-0033 위젯)
- 옵션 정의 UI (옵션명 + 값 추가)
- **옵션 조합 → Variant 표 자동 생성** (가격·재고·SKU 일괄/개별 입력)
- 임시저장(DRAFT) / 판매중(ACTIVE) 전환
- 수정 시 기존 값 로드, 옵션 변경 처리
- 미리보기 (구매자 화면 기준)

### 제외
- 상품 목록·재고 관리 (TASK-0035)
- 검색 노출 (M06)

## 3. 요구사항

- [ ] 카테고리를 바꾸면 속성 폼이 즉시 바뀐다
- [ ] 옵션 3 × 4 를 넣으면 Variant 12행 표가 생성된다
- [ ] Variant 가격·재고를 일괄 입력할 수 있다
- [ ] 임시저장 후 이어서 작성할 수 있다
- [ ] 필수 속성이 비면 저장이 막히고 해당 필드에 오류가 표시된다

## 4. 설계

```
① 기본 정보 → ② 카테고리 선택 → ③ 속성 폼 (자동 생성) → ④ 이미지
                                   ↓
④ 옵션 정의 → ⑤ Variant 표 (조합 자동 생성) → ⑥ 가격·재고 입력 → 저장
```

카테고리 변경 시 이미 입력한 속성값은 **키가 같으면 유지**하고 나머지는 버린다. 전부 날리면 카테고리를 잘못 골랐다가 되돌릴 때 다시 입력해야 한다.

Variant 표는 행이 많아질 수 있으므로 일괄 입력(전체 가격 동일 적용)을 먼저 제공한다.

## 5. 구현 계획

1. 폼 골격 + 기본 정보
2. 카테고리 선택 → 속성 폼 연동
3. 이미지 위젯 연결
4. 옵션 정의 UI
5. Variant 표 생성·일괄 입력
6. 임시저장·발행
7. 수정 모드 (옵션 변경 처리)
8. 미리보기
