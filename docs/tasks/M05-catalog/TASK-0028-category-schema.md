## 1. 목적

자기 참조 카테고리 트리와 조회 API 를 만든다. 하위 전체 조회가 한 번의 쿼리로 되게 한다.

## 2. 범위

### 포함
- `Category` — `parentId`, `name`, `slug`, `depth`, `path`, `sortOrder`, `isActive`
- `path` 캐시 유지 (생성·이동 시 자신과 하위 갱신)
- 트리 조회 API (전체 / 특정 노드 하위)
- 이동·정렬 API
- 순환 참조 방지
- 최대 깊이 제한 (3단계)

### 제외
- 관리자 화면 (TASK-0029)
- 카테고리별 상품 목록 (M06)

## 3. 요구사항

- [ ] 3단계 트리를 만들 수 있다
- [ ] 하위 전체를 한 쿼리로 조회할 수 있다
- [ ] 자기 자신이나 자손 아래로 이동할 수 없다
- [ ] 이동하면 하위 노드의 `path` 와 `depth` 가 함께 갱신된다

## 4. 설계

```
path 예시: "/1/5/12/"     → 하위 전체 조회는 path LIKE '/1/5/%'
```

인접 리스트만 쓰면 하위 전체 조회에 재귀가 필요하다. `path` 를 캐시하면 인덱스 하나로 끝난다. 대신 이동 시 하위를 함께 갱신해야 하는데, 카테고리 이동은 드문 작업이라 이쪽이 유리하다.

## 5. 구현 계획

1. 스키마·인덱스·마이그레이션
2. 생성 시 `path`·`depth` 계산
3. 트리 조회 API
4. 이동·정렬 API + `path` 재계산
5. 순환 참조·깊이 검증
6. 단위 테스트 (트리 조작)
