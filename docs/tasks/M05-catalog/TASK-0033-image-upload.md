## 1. 목적

TASK-0011 의 presigned URL 경로를 실제 UI 로 감싼다. 판매자가 여러 이미지를 올리고 순서를 정할 수 있게 한다.

## 2. 범위

### 포함
- 업로드 위젯 (드래그&드롭 + 파일 선택)
- 다중 업로드, 진행률 표시
- 클라이언트 리사이즈 (업로드 전 축소로 용량·시간 절감)
- 순서 변경, 대표 이미지 지정
- 삭제 (R2 객체 + DB 행)
- 업로드 실패 재시도
- 인증 연동 — presign 은 판매자만 가능

### 제외
- 서버 사이드 이미지 변환·썸네일 생성
- 이미지 CDN 최적화

## 3. 요구사항

- [ ] 이미지 5장을 한 번에 올릴 수 있다
- [ ] 업로드 중 진행률이 보인다
- [ ] 순서를 바꾸면 상품 상세의 표시 순서가 바뀐다
- [ ] 로그인하지 않으면 presign 이 거부된다
- [ ] 업로드 실패 시 재시도할 수 있다

## 4. 설계

```
파일 선택 → 클라이언트 리사이즈(최대 2000px) → presign 요청 → R2 직접 PUT → DB 에 URL 기록
```

**클라이언트 리사이즈를 넣는 이유**: 원본 사진은 5~10MB 가 흔하다. 서버 변환 없이 용량 문제를 해결하는 가장 싼 방법이다.

## 5. 구현 계획

1. presign 엔드포인트에 인증·역할 가드 추가 (TASK-0011 보완)
2. 클라이언트 리사이즈 유틸
3. 업로드 위젯 (드래그&드롭, 진행률)
4. 순서·대표 이미지 관리
5. 삭제 처리 (R2 + DB)
6. 실패 재시도
