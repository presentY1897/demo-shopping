## 규칙

- 모든 TASK 문서는 `docs/tasks/TASK-TEMPLATE.md` 를 복사해 작성한다.
- **6장 완료 기준(Definition of Done)은 필수**이며, 각 항목은 측정 방법과 목표값을 가져야 한다.
- 완료 기준을 모두 충족하기 전에는 상태를 `완료` 로 바꾸지 않는다.
