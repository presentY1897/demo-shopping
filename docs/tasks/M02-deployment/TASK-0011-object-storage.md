## 1. 목적

Cloudflare R2 버킷을 만들고 브라우저에서 직접 업로드하는 경로를 뚫는다. 서버가 파일을 거치지 않게 한다.

## 2. 범위

### 포함
- R2 버킷 생성 (개발용 / 운영용 분리)
- API 에 presigned URL 발급 엔드포인트
- 버킷 CORS 설정
- 공개 읽기 도메인 연결 (`cdn.<도메인>` 또는 R2 public URL)
- 업로드 제약: 확장자 화이트리스트, 용량 상한, 파일명 규칙
- 업로드 왕복 검증용 임시 스크립트

### 제외
- 상품 이미지 관리 UI (M05)
- 이미지 리사이즈·최적화 (필요 시 별도 TASK)

## 3. 요구사항

- [ ] presigned URL 로 브라우저에서 직접 업로드된다
- [ ] 업로드된 파일이 공개 URL 로 조회된다
- [ ] 허용되지 않은 확장자·용량은 발급 단계에서 거부된다
- [ ] presigned URL 이 짧은 시간 후 만료된다

## 4. 설계

```
브라우저 → API: POST /api/v1/uploads/presign { filename, contentType, size }
API → 브라우저: { uploadUrl, publicUrl, key }   (검증 통과 시, 5분 만료)
브라우저 → R2:  PUT uploadUrl (파일 본문)
```

| 항목 | 값 |
| --- | --- |
| 키 규칙 | `products/{sellerId}/{uuid}.{ext}` |
| 허용 형식 | jpg, jpeg, png, webp |
| 용량 상한 | 5MB |
| URL 만료 | 5분 |

## 5. 구현 계획

1. R2 버킷 2개 생성 (dev / prod), API 토큰 발급
2. S3 호환 클라이언트 설정 (AWS SDK)
3. presign 엔드포인트 + 검증 로직
4. 버킷 CORS 설정
5. 공개 읽기 경로 연결
6. 업로드 왕복 검증

- **4장 해당 없음**
