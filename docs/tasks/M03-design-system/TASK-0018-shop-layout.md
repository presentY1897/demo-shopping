## 1. 목적

구매자 앱의 공통 레이아웃과 밀도 토글 UI 를 만든다. 이후 모든 shop 화면이 이 레이아웃 위에 올라간다.

## 2. 범위

### 포함
- 헤더: 로고, 카테고리 네비, 검색창 자리, 장바구니·마이페이지 아이콘 자리
- 푸터
- **밀도 토글 UI** — 3단계 선택, 현재 값 표시
- 모바일 네비게이션 (햄버거·바텀시트)
- 반응형 브레이크포인트 적용
- 확인용 임시 페이지 교체
- 로딩 표시 (라우트 전환)

### 제외
- 검색 기능 (M06) — 입력창 자리만
- 장바구니 개수 배지 (M07) — 자리만
- 로그인 상태 표시 (M04) — 자리만

## 3. 요구사항

- [ ] 세 밀도 단계에서 헤더·푸터가 정상 표시된다
- [ ] 360 / 768 / 1440px 에서 레이아웃이 깨지지 않는다
- [ ] 밀도 토글이 즉시 반영되고 새로고침 후에도 유지된다
- [ ] 키보드만으로 네비게이션을 순회할 수 있다

## 4. 설계

밀도 토글은 헤더 우측에 둔다. 아이콘 3개(넓게·보통·조밀) 또는 세그먼트 컨트롤.

이 기능이 이 사이트의 차별점이므로 **찾기 쉬운 위치**에 두되, 미니멀 원칙에 어긋나지 않게 아이콘만 노출하고 툴팁으로 설명한다.

## 5. 구현 계획

1. 헤더 구조 (데스크톱)
2. 모바일 네비게이션
3. 밀도 토글 UI + 컨텍스트 연결
4. 푸터
5. 라우트 전환 로딩
6. 임시 페이지 교체, 3단계 × 3뷰포트 확인
