## 1. 목적

판매자·관리자 앱이 공유하는 콘솔 레이아웃을 만든다. 사이드바 메뉴 구성만 다르고 구조는 같다.

## 2. 범위

### 포함
- `packages/ui` 의 콘솔 셸 (사이드바 + 상단바 + 본문)
- 사이드바: 메뉴 정의를 prop 으로 받아 렌더, 접기·펼치기, 현재 경로 강조
- 상단바: 페이지 제목, 사용자 메뉴 자리, 알림 자리
- 페이지 헤더 규약 (제목 + 액션 버튼 + 필터 영역)
- 두 앱에 적용, 메뉴는 `docs/design/pages.md` 기준으로 구성
- 콘솔은 밀도 2단계 고정

### 제외
- 각 메뉴의 실제 화면 (해당 도메인 마일스톤)
- 권한에 따른 메뉴 표시 제어 (M04)

## 3. 요구사항

- [ ] 두 앱이 같은 셸 컴포넌트를 쓰고 메뉴만 다르다
- [ ] 현재 경로에 해당하는 메뉴가 강조된다
- [ ] 1024px 미만에서 사이드바가 접힌다
- [ ] 밀도 토글이 노출되지 않는다

## 4. 설계

```
<ConsoleShell menu={SELLER_MENU} title="주문 관리" actions={<Button/>}>
```

메뉴 정의는 각 앱이 소유하고 셸은 렌더만 한다. M04 에서 권한 필터를 이 정의에 얹는다.

**콘솔 밀도를 고정하는 이유**: 관리 화면은 정보 밀도가 높은 것이 항상 정답이다. 미니멀하게 만들면 오히려 쓰기 나빠진다. (D-033)

## 5. 구현 계획

1. 콘솔 셸 컴포넌트
2. 사이드바 (메뉴 렌더·강조·접기)
3. 상단바 + 페이지 헤더 규약
4. seller 앱 적용 + 메뉴 정의
5. admin 앱 적용 + 메뉴 정의
6. 반응형 확인
