# M03. 디자인 시스템

밀도 3단계를 `apps/shop` 전체에 적용하기로 했으므로(D-033), **컴포넌트를 만들기 전에** 토큰 시스템이 있어야 한다. 나중에 확대하려면 만든 것을 전부 고쳐야 한다.

**완료 조건**: 밀도 토글을 누르면 shop 앱의 간격·타이포·그리드가 3단계로 바뀌고, 세 앱이 같은 컴포넌트 세트를 쓴다.

> **선행 정정 (2026-09-03)** — TASK-0014 의 선행은 M02 가 아니라 **M01** 이다. 토큰은 CSS 변수와 Tailwind 프리셋이라 배포와 무관하고, 필요한 것은 M01 이 만든 Tailwind 공통 프리셋뿐이다. M02 는 사용자 계정 준비를 기다리는 중이므로 이 마일스톤을 먼저 진행한다.
