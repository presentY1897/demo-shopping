## 1. 목적

장바구니 화면을 만든다. **판매자별 묶음과 그룹별 배송비**가 눈에 보이게 한다 — 마켓플레이스 구조를 사용자가 이해하는 첫 지점이다.

## 2. 범위

### 포함
- 판매자별 그룹 표시, 그룹 헤더에 브랜드명·배송비
- 수량 변경·삭제·선택 삭제
- 전체·그룹·개별 선택 체크박스
- 선택 항목 기준 합계 (상품금액·배송비·총액)
- 품절·가격변동 항목 표시와 처리
- 무료배송 조건까지 남은 금액 안내
- 빈 장바구니 상태
- 헤더 장바구니 개수 배지 연결
- 주문하기 → 주문서 이동

### 제외
- 주문서 (TASK-0050)
- 쿠폰·적립금 (M11)

## 3. 요구사항

- [ ] 판매자별로 묶여 보이고 그룹마다 배송비가 표시된다
- [ ] 선택한 항목만 합계에 반영된다
- [ ] 품절 항목은 선택할 수 없고 이유가 표시된다
- [ ] 수량 변경이 합계에 즉시 반영된다

## 4. 설계

```
[✓] 브랜드A                      배송비 3,000원
    [✓] 울 코트 / 블랙 / M   1개   189,000원
    [✓] 니트 / 그레이 / L     2개    59,000원
    ─ 무료배송까지 11,000원 남음

[✓] 브랜드B                      무료배송
    [ ] (품절) 스니커즈 / 270      — 재고 없음
```

품절 항목은 **삭제하지 않고 남긴다.** 사용자가 뭘 담았는지 기억하고 재입고를 기다릴 수 있어야 한다.

## 5. 구현 계획

1. 그룹 목록 렌더
2. 선택 상태 관리 (전체·그룹·개별 연동)
3. 수량 변경·삭제
4. 합계 계산 표시
5. 품절·가격변동 처리
6. 무료배송 안내
7. 빈 상태 + 헤더 배지
