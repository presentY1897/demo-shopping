## 1. 목적

주문서 화면을 만든다. **진입 시 재고가 예약되고, 결제 직전까지의 흐름이 완성**된다.

## 2. 범위

### 포함
- 주문 항목 확인 (판매자별 그룹)
- 배송지 선택·신규 입력 (TASK-0027 배송지 재사용)
- 배송 요청사항
- 금액 요약 (상품금액·할인·배송비·총액)
- 쿠폰·적립금 영역 **자리** (M11 연결)
- 결제수단 선택 **자리** (M08 연결)
- **진입 시 재고 예약 + 남은 시간 표시**
- 예약 만료 시 안내·재시도
- 약관 동의
- 주문하기 → 주문 생성 → 결제 페이지 이동
- 이탈 시 예약 해제

### 제외
- 실제 결제 (M08)
- 쿠폰·적립금 적용 (M11)

## 3. 요구사항

- [ ] 주문서에 진입하면 재고가 예약된다
- [ ] 남은 시간이 표시되고 만료되면 안내가 나온다
- [ ] 페이지를 벗어나면 예약이 해제된다
- [ ] 금액이 장바구니와 일치한다
- [ ] 배송지를 선택하거나 새로 입력할 수 있다

## 4. 설계

```
장바구니 → [주문하기] → 주문서 진입
                         ├ 재고 예약 (15분)
                         ├ 타이머 표시
                         └ 이탈(beforeunload/라우트 변경) → 예약 해제 요청
```

**예약 해제를 이탈 시 시도하되 의존하지 않는다.** 브라우저를 강제 종료하면 신호가 안 온다. 만료 스케줄러(TASK-0051)가 최종 안전망이다.

타이머는 남은 시간이 3분 이하일 때 강조한다. 결제 중 만료되면 사용자가 당황하므로 미리 알린다.

## 5. 구현 계획

1. 주문서 데이터 로딩 + 재고 예약
2. 항목·금액 요약 표시
3. 배송지 선택·입력
4. 타이머 + 만료 처리
5. 쿠폰·결제수단 자리 배치
6. 약관 동의 + 주문 생성 연결
7. 이탈 시 해제
