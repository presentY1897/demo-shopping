# M07. 장바구니 · 주문

장바구니부터 주문 생성까지를 만든다. **주문 2단 분할(D-023)과 재고 예약(D-026)이 실제로 동작하는 마일스톤**이다.

금액 계산은 "할인 목록을 받아 계산하는" 구조로 먼저 만들고, M11 에서 쿠폰·적립금 규칙을 꽂는다. 주문 로직을 두 번 만들지 않기 위해서다. (D-036)

**완료 조건**: 여러 판매자 상품을 담아 주문서까지 가면 재고가 예약되고, 판매자별로 분할된 주문이 생성된다. — **충족 (2026-09-05)**

담기부터 주문 접수까지가 이어진다. 결제는 M08 이고, 그때까지 주문은 `PAYMENT_PENDING` 으로 남으며 잡아 둔 재고는 만료 스케줄러가 되돌린다.
