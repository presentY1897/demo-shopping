## 1. 목적

판매자가 "내가 얼마 벌었나"를 확인하는 화면을 만든다. 판매자 콘솔의 완성 지점이다.

## 2. 범위

### 포함
- 매출 대시보드 — 기간별 매출 추이, 주문 수, 평균 주문금액, 인기 상품
- 정산 내역 목록 (회차·상태·지급액)
- 정산서 상세 (계산 근거 — 관리자와 같은 내역)
- 정산 예정 금액 (구매확정 대기 중 + 확정됐으나 미정산)
- 차트 (매출 추이)
- 기간 필터·비교 (전주·전월 대비)

### 제외
- 관리자 화면 (TASK-0081)

## 3. 요구사항

- [ ] 자기 정산 내역만 보인다
- [ ] 정산액 계산 근거를 판매자도 볼 수 있다
- [ ] 정산 예정 금액이 표시된다
- [ ] 매출 추이가 차트로 보인다
- [ ] 수수료와 쿠폰 부담이 구분되어 표시된다

## 4. 설계

**판매자에게도 계산 근거를 그대로 보여준다.** 정산액만 던지면 "왜 이 금액이냐"는 문의가 생긴다. 수수료·쿠폰 부담·반품 차감을 분리해 보여주면 스스로 확인할 수 있다.

**정산 예정 금액**을 두 단계로 나눈다.
- 확정 대기: 배송완료됐으나 구매확정 전 (아직 확정 아님)
- 정산 대기: 구매확정됐으나 정산서 생성 전

차트는 `dataviz` 원칙에 따라 단순하게 — 기간별 매출 라인 하나로 시작한다.

## 5. 구현 계획

1. 매출 집계 API (기간별)
2. 대시보드 화면 + 차트
3. 정산 내역 목록
4. 정산서 상세 (근거 표시)
5. 정산 예정 금액 계산
6. 기간 비교
