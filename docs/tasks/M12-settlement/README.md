# M12. 정산

**앞서 정한 것들이 전부 만나는 마일스톤**이다. 쿠폰 부담 주체, 적립금, 반품 차감, 구매확정이 정산 한 줄로 수렴한다. (D-032)

```
지급액 = 판매액 − 플랫폼 수수료 − 판매자 부담 쿠폰 − 반품 차감
```

실제 이체는 없다. 관리자가 "지급완료" 처리하면 상태만 바뀐다.

**완료 조건**: 구매확정된 주문이 주간 정산서로 집계되고, 금액이 `pricing.md` 5장 규칙과 정확히 일치한다.
