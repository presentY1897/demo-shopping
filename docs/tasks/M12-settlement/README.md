# M12. 정산

**앞서 정한 것들이 전부 만나는 마일스톤**이다. 쿠폰 부담 주체, 적립금, 반품 차감, 구매확정이 정산 한 줄로 수렴한다. (D-032)

```
지급액 = 판매액 − 플랫폼 수수료 − 판매자 부담 쿠폰 − 반품 차감
```

실제 이체는 없다. 관리자가 "지급완료" 처리하면 상태만 바뀐다.

**완료 조건**: 구매확정된 주문이 주간 정산서로 집계되고, 금액이 `pricing.md` 6장 규칙과 정확히 일치한다.

**✅ 충족.** `settlement-journey.spec.ts` 가 장바구니에서 정산서까지 한 번에 걸어 확인한다 — 손님이 10,000원짜리를 플랫폼 쿠폰 3,000원과 판매자 쿠폰 1,000원으로 6,000원에 사면, 판매자는 **정가 기준** 10,000원에서 수수료 1,000원과 자기가 부담한 1,000원만 빠진 **8,000원**을 받는다. 차액 중 3,000원은 플랫폼이 진 비용이다 (D-029).
