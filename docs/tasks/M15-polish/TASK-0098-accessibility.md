## 1. 목적

전 화면의 접근성을 점검하고 기준 미달을 수정한다. **밀도 3단계 × 화면**의 조합이 많아 전체 점검이 필요하다.

## 2. 범위

### 포함
- 전 화면 Lighthouse Accessibility 측정
- 키보드 전용 조작 전수 확인
- 스크린리더 확인 (주요 흐름: 검색 → 상세 → 장바구니 → 주문)
- 색 대비 검사 (밀도 3단계 전부)
- 폼 레이블·오류 연결 확인
- 이미지 대체 텍스트
- 포커스 표시·순서
- 동적 콘텐츠 알림 (aria-live) — 토스트·장바구니 담기 등
- 차트 대체 표 제공

### 제외
- 완전한 WCAG AAA 준수

## 3. 요구사항

- [ ] 전 화면이 Lighthouse a11y 90점 이상이다
- [ ] 마우스 없이 구매 흐름을 완주할 수 있다
- [ ] 색 대비가 밀도 3단계 모두에서 AA 를 만족한다
- [ ] 폼 오류가 스크린리더로 전달된다
- [ ] 동적 변화가 알려진다

## 4. 설계

**밀도 3단계를 모두 검사하는 이유**: 맥시멀 단계는 폰트가 작아지고 여백이 줄어 대비와 터치 영역이 나빠질 수 있다. 표준에서만 통과하면 의미가 없다.

**구매 흐름 키보드 완주**를 핵심 기준으로 삼는다. 개별 컴포넌트가 접근 가능해도 흐름이 끊기면 쓸 수 없다.

## 5. 구현 계획

1. 전 화면 자동 측정 (Lighthouse CI)
2. 미달 항목 목록화
3. 키보드 전수 점검
4. 스크린리더 주요 흐름 점검
5. 대비 수정 (밀도별)
6. aria-live·레이블 보완
7. 재측정
