## 목적과 근거

PR141 배포 후 실제 모바일 두 상품 구매는 성공했지만 승인·확정 요청이 브라우저의 기본 5초 제한에 걸려 복구 조회를 거쳤다. 주문 버튼부터 완료까지 26,475ms였다. 앞선 운영 HTTP 측정은 승인5,270ms·확정7,740ms였으며 서버 transaction은 정상 완료했다.

## 설계와 범위

결제 생성·승인·확정 쓰기에만 기존 request timeoutMs 옵션으로 15초를 준다. 토스 생성·승인도 같은 결제 경계를 사용한다. 일반 조회와 전역 기본5초, API transaction5초, 멱등성·중복 제출 방지·응답 유실 복구는 유지한다. 화면은 기존 진행 상태와 제출 잠금을 유지한다. 정상 응답까지 기다리는 변경이며 서버 성능 개선의 대체재로 삼지 않는다.

## 구현 순서

설계 기록 → 실제 API client를 통한 지연/시간 초과 회귀 → 결제 wrapper 적용 → 전체 품질 게이트 → PR·배포 → 같은 운영 모바일 구매 비교. 기존 TASK0133의 배포 검증도 기록한다.
