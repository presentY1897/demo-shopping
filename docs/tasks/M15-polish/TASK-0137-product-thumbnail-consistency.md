## 1. 문제

사용자가 최근 본 상품의 썸네일 깨짐과 화면별 처리 불일치를 제보했다. 장바구니·주문서·주문 상세는 ProductThumbnail을 쓰지만, 홈/상세 최근 본 상품 스트립·최근 본 전체 목록·찜 목록은 thumbnailUrl을 img에 직접 넣는다. 동일한 구형 시드 CDN 주소라도 후자의 화면에서는 로컬 동일 바이트 자산으로 보정되지 않고 실패 대체 표시도 없다. 최근 본 상품은 비로그인 localStorage와 로그인 서버 응답 모두 이 경로를 따른다.

## 2. 범위 및 설계

기존 ProductThumbnail을 위 세 컴포넌트에 재사용한다. API 응답/DB/브라우저 저장값을 바꾸지 않고 표시 시점에 같은 URL 보정과 실패 정책을 적용한다. 기존 링크 이름·그리드·이미지 크기·목록 순서·삭제/찜 동작은 유지한다. 이미지 원본이 없는 경우 다른 상품 이미지로 대체하지 않는다.

상품 상세 갤러리와 검색 카드는 이미 productImageUrl을 적용한다. 리뷰 사진과 스토어 로고는 상품 썸네일이 아니므로 이번 변경에 포함하지 않는다. 새 공통 컴포넌트나 디자인 시스템은 만들지 않는다.

## 3. 검증

기존 최근 본 상품/찜 목록 상호작용 검사에 구형 시드 URL 표시와 error 이벤트 후 깨진 img 제거 검증을 추가한다. 공통 컴포넌트의 null/빈 주소/실패 후 URL 변경 검사는 재사용한다. 브라우저에서 최근 본 목록/홈 스트립과 찜 목록의 이미지 로드를 확인하고, 기존 저장 이력을 지우지 않아도 보정되는지 확인한다.

## 검증 기록
