## 1. 목적

발송된 배송이 시간에 따라 자동으로 진행되게 한다. **데모에서 실제 배송을 기다릴 수 없으므로**, 압축된 시간으로 전 과정을 보여준다.

## 2. 범위

### 포함
- 배송 진행 스케줄러 (집화 → 간선 → 배송출발 → 배송완료)
- 데모 모드 시간 압축 (예: 단계당 2분 → 전체 8분)
- 일반 모드 시간 (단계당 수 시간)
- 배송완료 시 SellerOrder DELIVERED 전환
- 수동 진행 API — 데모에서 즉시 다음 단계로 (관리자·판매자)
- 배송 지연·분실 시나리오 재현 (선택)
- 헬스체크에 스케줄러 상태 노출

### 제외
- 실제 택배사 연동

## 3. 요구사항

- [ ] 발송 후 시간이 지나면 자동으로 배송 단계가 진행된다
- [ ] 데모 모드에서는 몇 분 내 배송완료까지 도달한다
- [ ] 배송완료 시 주문 상태가 전환된다
- [ ] 수동으로 다음 단계로 넘길 수 있다
- [ ] 스케줄러 상태를 헬스체크로 알 수 있다

## 4. 설계

```
SHIPPED → (2분) 집화 → (2분) 간선상차 → (2분) 배송출발 → (2분) 배송완료 → DELIVERED
```

**시간 압축이 데모 품질을 좌우한다.** 실제 배송 시간을 쓰면 방문자가 배송완료를 볼 수 없고, 구매확정·정산·반품까지의 흐름을 전혀 시연하지 못한다. 데모 계정 수명이 24시간이므로 그 안에 전 과정이 끝나야 한다.

**수동 진행 버튼**을 함께 둔다. 시연할 때 2분도 기다리기 어렵다.

## 5. 구현 계획

1. 진행 단계 정의
2. 스케줄러 (주기 1분, 대상 조회 후 다음 단계 진행)
3. 모드별 시간 설정 (환경변수)
4. DELIVERED 전환 연동
5. 수동 진행 API + 버튼
6. 헬스체크 연동
7. 지연·분실 시나리오 (선택)
