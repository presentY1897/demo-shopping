# M09. 배송 · 주문관리

주문 상태 머신을 구현하고 판매자·구매자 양쪽 화면을 만든다. 배송은 **도메인·상태 전이를 실제와 동일하게 구현하되 운송사 연동 없이 가상 처리**한다. (D-010)

**완료 조건**: 판매자 탭에서 발송 처리하면 구매자 탭에서 상태가 바뀌고, D+7 에 구매확정이 자동으로 이뤄진다.
