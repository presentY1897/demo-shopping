**API 누적 시간이 세션 시간의 1.12배**다. 서브에이전트를 최대 3개까지 동시에 돌린 결과이며, 이것이 12시간 실작업으로 72,937줄을 만든 배경이다.

## 8. 해석

1. **비용의 75% 가 서브에이전트, 그 대부분이 캐시 읽기다.**
   19.5억 캐시 읽기 토큰 = $976.69(총액의 77%). 에이전트 1개당 평균 4,400만 토큰.
   → 병렬화는 **시간을 사는 대신 토큰을 지불하는 거래**다. 12시간에 72,937줄을 얻었지만, 단일 스레드였다면 컨텍스트 재사용은 훨씬 좋고 대신 며칠이 걸렸을 것이다.

2. **계획 1 : 실행 92 — 설계 단계의 결정이 압도적으로 값싸다.**
   TASK 문서 1개 $0.48 vs 구현 1개 $43.93. 세션 01 회고의 "범위를 늘릴 때 환산해서 보라"는 개선안이 이번 수치로 확정됐다.

3. **문서 선행 투자는 질문 수로 회수됐지만, 손으로 하는 일은 못 줄인다.**
   `AskUserQuestion` 33 → 1. 그런데 외부 설정 안내가 35회로 늘어 **세션 마지막 프롬프트까지 그 유형**이었다. 결정은 미리 풀 수 있어도 **사람이 브라우저에서 눌러야 하는 일은 미리 풀 수 없다.**

4. **문서로 정한 규칙은 두 번 무시됐고, 강제 수단으로 승격됐다.**
   커밋 트레일러(§5-E)와 CI(D-203)가 같은 형태다. **CLAUDE.md 에 쓰는 것과 훅·브랜치 보호로 막는 것은 다르다.**

5. **테스트 전략은 계획 105개에 없던 구멍이었고, 사용자가 찾았다.**
   커버리지 80% 게이트는 있었지만 **모킹 경계와 DB 통합 테스트 계층**이 없었다. 계획 문서의 완성도는 "항목이 있느냐"가 아니라 **"경계가 그어져 있느냐"** 로 봐야 한다.

6. **일회성 승인이 상시 규칙으로 번졌다.** D-212 정정(§5-D). 사용자의 "다 승인해"는 그 순간의 목록에 대한 것이었다. **결정을 기록할 때 유효 범위(닫힌 집합인지 상시 규칙인지)를 명시해야 한다.**

7. **3일차에 사용자의 역할이 바뀌었다.** 1~2일차는 결정자·검토자였는데 3일차는 **처리량 관리자**였다(§5-F). 게이트를 완화하고 병목을 물었다. 자율 실행이 길어질수록 사람의 일은 "무엇을 만들까"에서 "왜 안 나아가지"로 옮겨간다.

8. **컨텍스트가 92% 까지 찼다.** 09-03 20:00 요청의 캐시 읽기가 923,203 토큰, 3분 뒤 압축. 본 스레드가 32개 에이전트의 보고를 전부 받아 안는 구조라 필연적이다.

## 부록: 측정 방법

- **1차 근거**: 세션 파일의 `cost-state` 레코드 — `totalCostUSD`, `modelUsage`(모델별 토큰·비용), `totalDuration`, `totalAPIDuration`, `totalToolDuration`. 서브에이전트를 포함한 하네스 자체 회계이며, 이 세션에는 3개가 있다(§2).
- **2차 근거**: 트랜스크립트의 `message.usage`(본 스레드만). `message.id` 중복 제거 필수(assistant 레코드 1,904 → 요청 1,071).
- **주의 1**: 토큰별 정가로 성분을 재계산하면 하네스 합계와 몇 % 차이가 난다. 서브에이전트의 캐시 TTL 구성(5분/1시간)이 트랜스크립트에 남지 않아 정확히 재현되지 않기 때문이다. **본문 총액은 하네스 값을 그대로 썼고, 성분 비율은 근사치다.**
- **주의 2**: 실작업 시간은 "레코드 간 10분 초과 공백"을 제외한 값이다. 하네스의 `totalDuration`(20:37:00)과는 정의가 달라 일치하지 않는다.
- **단가**: Opus 5 — 입력 $5 / 출력 $25 / 캐시 쓰기 5분 $6.25 · 1시간 $10 / 캐시 읽기 $0.50 (per MTok). Haiku 4.5 — 입력 $1 / 출력 $5.
- **주의 3**: 모두 **API 정가 기준 환산값**이다. 실제 청구는 구독 플랜에 따라 다르다.

# cost-state 읽기 — 서브에이전트를 쓰는 세션의 1차 근거
import json
for line in open(TRANSCRIPT):
    r = json.loads(line)
    if r.get('type') == 'cost-state':
        print(f"${r['totalCostUSD']:.2f}",
              f"duration={r['totalDuration']/3.6e6:.2f}h",
              f"api={r['totalAPIDuration']/3.6e6:.2f}h")
        for model, u in r['modelUsage'].items():
            print(f"  {model}: out={u['outputTokens']:,}"
                  f" cacheRead={u['cacheReadInputTokens']:,}"
                  f" ${u['costUSD']:.2f}")
