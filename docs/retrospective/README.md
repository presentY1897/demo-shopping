# 세션 회고 (Retrospective)

Claude Code 세션의 **작업 이력·소요 시간·토큰 비용**을 사후 분석한 문서를 모은다.

| 성격 | 내용 |
| --- | --- |
| 무엇을 담나 | 대화 흐름, 사용자가 준 피드백, 산출물, 토큰·비용, 시간 분해, 다음 세션 개선안 |
| 무엇을 담지 않나 | 결정 내용 자체(→ `decisions/`), 설계(→ `design/`), 작업 계획(→ `tasks/`) |
| 갱신 방식 | 세션당 1개 파일. **덮어쓰지 않고 추가한다.** |

파일명은 `YYYY-MM-DD-session-NN.md`(세션 **시작일** 기준)로 `decisions/` 의 세션 이력 파일과 짝을 맞춘다.

> 서브에이전트를 쓰는 세션은 트랜스크립트 합산으로 비용을 측정할 수 없다. 세션 파일의 `cost-state` 레코드를 근거로 삼는다 — [session-02 §2](./2026-09-02-session-02.md#2--이-세션은-트랜스크립트만으로-측정되지-않는다) 참고.
