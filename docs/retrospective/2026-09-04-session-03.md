### A. "계속 진행해" — 위임의 언어 (29회)

### B. **"…라니까" — 같은 지시를 반복해야 했다 (2회) + 1분 간격 재전송 (1회)**

> "응 마일스톤 **계속 진행하라니까**" (09-06 18:14)
> "응 승인된 task **다 하라니까**" (09-07 07:54)
> "마일스톤 끝까지 진행해…" (14:29) → **"마일스톤 14 끝까지 진행해…"** (14:30)

`-라니까` 는 이미 말한 것을 다시 말할 때 쓰는 종결어미다. 14:29→14:30 의 1분 간격 재전송은 **범위를 좁혀 다시 말한** 경우다 — "마일스톤" 이 "마일스톤 14" 로 바뀌었다.
**위임을 명시해도 에이전트가 멈추거나 범위를 넓게 잡아, 사용자가 같은 말을 29번 반복했다.**

## 8. 해석

1. **결정 60 → 15 → 2. 설계 투자는 세 번째 세션에서 가장 크게 회수됐다.**
   77시간 자율 실행 동안 `DECISIONS.md` 에 새로 오른 것이 2건뿐이다. 개입 밀도도 8.0 → 1.4/h 로 떨어졌다.

2. **줄은 싸지고 덩어리는 비싸졌다.** 코드 1,000줄당 $17.47 → $12.42(−29%), 실작업 시간당 $103.6 → $69.3(−33%). 반대로 PR 1개당 +145%, 커밋 1개당 +153%.
   → **성숙한 코드베이스에서는 양산이 싸지고 통합이 비싸진다.**

3. **세션 안에서도 뒤로 갈수록 비싸진다 — 커밋 1개당 $1.05 → $14.35 (13.6배).**
   컨텍스트가 96.6% 까지 차서 요청 1회의 바닥값이 계속 오르고, 마지막 국면 작업(관리자 화면·마무리·포트폴리오 문서)이 더 얽혀 있다.
   **"오래 돌릴수록 효율이 오른다"는 직관은 이 데이터로 반박된다.**

4. **모델 선택의 지렛대는 거의 쓰이지 않았다.** `Agent` 82개 중 절감이 되는 `sonnet` 지정은 4개뿐(총액의 0.16%)이고, 09-07 에 붙은 `opus` 10개는 **기본값과 같아 비용 효과가 없다.**
   조사·문서화·F-표 채우기처럼 판단이 가벼운 작업이 09-07 에 몰려 있었는데, 그게 정확히 Sonnet 으로 돌렸어야 할 일이었다.

5. **병목이 병렬 폭에서 직렬 도구 실행으로 옮겨갔다.** Bash 5,343회.

6. **위임을 29번 반복해야 했다.** §5-A·B. 두 번은 `-라니까`, 한 번은 1분 간격 재전송이었다.
   **자율 실행의 실질 상한은 컨텍스트나 비용이 아니라 "에이전트가 스스로 멈추거나 범위를 넓게 잡는 빈도"** 다.

7. **자율 실행이 길어지면 초기 규율부터 흐려진다.** 워크트리 구분(§5-E), 결정 9건 중 7건이 `DECISIONS.md` 에 오르지 못한 것(§5-D)이 같은 종류다.

8. **`cost-state` 가 45시간을 놓쳤지만, 추정은 오히려 정확해졌다.** 미반영 구간의 본 스레드가 실측이므로 실측 비중이 늘어 두 추정법의 차이가 ±4% → **±1%** 로 좁아졌다(§2).

9. **사용자는 자율 구간과 검토 구간을 스스로 나눴다.** 코드는 나흘 내내 위임했지만, **포트폴리오 문서는 "초안만 작성해봐, 내가 보면서 피드백"** 이라고 했다(§5-F). 밖으로 나가는 산출물에는 위임이 적용되지 않았다.

## 부록: 측정 방법

- **1차 근거**: 세션 파일의 `cost-state` 레코드 2개. 다만 **마지막 레코드가 09-06 00:42 에 멈춰 45시간 26분을 놓쳤다.**
- **2차 근거**: 트랜스크립트의 `message.usage`(본 스레드만). `message.id` 중복 제거 필수(assistant 레코드 8,562 → 요청 5,540).
- **잔여 구간 추정**: 본 스레드는 실측($864.07), 서브에이전트는 (a) 직전 구간 에이전트당 평균 $21.30 × 44개, (b) 직전 구간 서브에이전트/본 스레드 비율 1.007 × $864.07 두 가지로 계산해 **범위로 제시**했다.
- **시각 처리 주의**: 트랜스크립트 `timestamp` 는 UTC 다. KST 로 비교할 때 tz 인식 값에 9시간을 더하면 **경계 비교가 9시간 어긋난다.** naive KST 로 변환해 비교해야 한다(이 회고의 초기 계산에서 실제로 발생했던 오류다).
- **코드 줄 수**: `origin/main` 기준(`git ls-tree` + `git show`).
- **실작업 시간**: 레코드 간 10분 초과 공백을 제외한 값. 하네스 `totalDuration` 과는 정의가 다르다.
- **단가**: Opus 5 — 입력 $5 / 출력 $25 / 캐시 쓰기 5분 $6.25 · 1시간 $10 / 캐시 읽기 $0.50. Sonnet 5 — $2 / $10. Haiku 4.5 — $1 / $5. (per MTok)
- **주의**: 모두 **API 정가 기준 환산값**이며, 이 세션은 스냅샷 시점에 **진행 중**이다.
