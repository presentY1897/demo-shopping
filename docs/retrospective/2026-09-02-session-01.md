3. **결정을 앞에 모으면 뒤가 자율 실행이 된다.**

## 부록: 측정 방법과 재현

- **데이터 출처**: Claude Code 트랜스크립트 `~/.claude/projects/-home-hyun-project-demo-project-shopping/8c1af2a2-….jsonl` (1,066줄)

- **토큰**: 각 고유 메시지의 `message.usage` 합계. `cache_creation.ephemeral_1h_input_tokens` / `ephemeral_5m_input_tokens` 로 TTL 구분
- **비용**: Opus 5 공개 단가 — 입력 $5 / 출력 $25 / 캐시 쓰기 5분 $6.25 · 1시간 $10 / 캐시 읽기 $0.50 (per MTok). 1M 컨텍스트에 장문 할증 없음
- **시간**: 레코드 `timestamp`(UTC) 기준. 턴의 종료는 그 턴의 마지막 `assistant`/`user` 레코드로 잡는다(`system` 레코드는 세션 유휴 중에도 기록되므로 제외). 도구 대기 시간은 `tool_use` 블록과 대응 `tool_result` 의 시각 차. 모델 생성 시간 = 활성 시간 − 도구 대기
- **주의**: 이 수치는 **API 정가 기준 환산값**이다. 실제 청구는 구독 플랜/요금제에 따라 다르다

```python
# 재측정 스크립트 (요약본)
import json, collections
P = {'in':5.0, 'out':25.0, 'cw1h':10.0, 'cw5m':6.25, 'cr':0.50}   # $/MTok
recs = [json.loads(l) for l in open(TRANSCRIPT) if l.strip()]
seen, tot, cost = set(), collections.Counter(), 0.0
for r in recs:
    if r.get('type') != 'assistant':
        continue
    m = r['message']
    if m.get('id') in seen:
        continue                      # 스트리밍 중복 제거
    seen.add(m.get('id'))
    u  = m.get('usage') or {}
    cc = u.get('cache_creation') or {}
    w1, w5 = cc.get('ephemeral_1h_input_tokens', 0), cc.get('ephemeral_5m_input_tokens', 0)
    tot['out'] += u.get('output_tokens', 0)
    tot['cr']  += u.get('cache_read_input_tokens', 0)
    tot['w1']  += w1
    tot['w5']  += w5
    cost += (u.get('input_tokens', 0) * P['in']
             + u.get('output_tokens', 0) * P['out']
             + w1 * P['cw1h'] + w5 * P['cw5m']
             + u.get('cache_read_input_tokens', 0) * P['cr']) / 1e6
print(len(seen), dict(tot), f'${cost:.2f}')
```
