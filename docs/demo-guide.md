# 데모 체험 안내

세 역할에서 같은 주문을 보려면 **판매자 데모부터 발급**한다. 새 판매자는 공용 상품의
복사본을 소유하므로, 다른 판매자 상품을 먼저 산 주문이 새 스토어로 넘어오지 않는다.
앱의 [5분 둘러보기](https://shop.demo-shopping.com/guide)는 아래 동선을 짧게 소개한다.

## 준비

[판매자](https://seller.demo-shopping.com/login), [구매자](https://shop.demo-shopping.com/login),
[관리자](https://admin.demo-shopping.com/login)를 서로 다른 탭에 연다. 각 앱에서 데모 계정을 받는다.
같은 역할을 다시 발급하면 다른 계정이 되므로 진행 중인 탭에서는 재발급하지 않는다.
계정은 기본 24시간 유효하며 운영 정책에 따라 달라질 수 있다.

아래 5분은 둘러보기 목표이고 완주 실측값은 아니다. 서버 기동과 검색 색인 대기,
배송·구매확정·정산 배치 시간을 포함하지 않는다. 금액은 가상 카드로 처리된다.

## 1. 판매할 상품부터 정하기

판매자 데모를 발급받으면 상품 12개와 체험 주문 5건이 준비된 스토어가 생긴다. 상품 목록에서
두 상품을 고르고 스토어명과 상품명을 기록한다. 이름이 공용 상품과 같을 수 있으므로
**스토어명까지** 확인해야 한다.

상점에서 쉽게 찾고 싶으면 상품 편집에서 두 상품의 이름에 자신만의 짧은 문구를 붙여 저장한다.
검색 반영은 비동기라 곧바로 검색되지 않을 수 있다. 선택한 상품이 판매중이고 재고가 있는지 확인한다.

## 2. 해당 스토어에서 구매하기

구매자 탭에서 데모 계정을 받고, 앞에서 정한 상품을 검색한다. 상품 상세에서 판매자 이름이
앞의 스토어인지 확인한 다음 옵션을 골라 장바구니에 담는다. 표시 밀도를 바꿔 배치와 정보량도 비교한다.

부분 취소까지 보려면 **서로 다른 상품 두 개**를 담는다. 주문서에서 가상 카드로 결제하고
완료 화면의 주문번호를 기록한다. 주문 내역과 카드 사용 내역에서 주문·결제 금액을 확인한다.

## 3. 선택 체험: 발송 전에 일부 취소하기

판매자가 주문 확인·발송하기 전에 구매자 주문 상세의 취소 신청으로 들어간다.
두 상품 중 하나를 선택해 신청한다. 결제완료 상태의 취소는 자동 처리 경로를 사용한다.

주문이 이미 준비중이면 판매자 판단이 필요하며, 발송 이후는 반품 절차로 다룬다.
발송 뒤 즉시 부분 취소로 환불받는 순서로 안내하지 않는다.

카드 사용 가능 금액이 환불액만큼 복구됐는지 확인한다. 환불액은 상품 표시 가격과 반드시
같지 않다. 쿠폰 안분·적립금·배송비 조정은 클레임 상세의 내역을 기준으로 비교한다.

## 4. 판매자에게 같은 주문이 보이는지 확인하기

판매자 탭의 주문 목록에서 기록한 주문번호를 찾는다. 처음부터 제공되는 체험 주문과
혼동하지 않는다. 남아 있는 상품·금액을 확인하고 주문 확인·발송을 처리한다.
구매자 탭의 주문 상세에서 배송조회를 누르면 같은 가상 운송장과 배송중 상태가 보인다.

## 5. 관리자 화면에서 같은 거래 확인하기

관리자 데모를 받고 주문 관리에서 같은 주문번호를 검색해 금액과 배송 상태를 대조한다.
상품 관리에서는 해당 데모 상품을 검색해 내리기·다시 올리기를 체험할 수 있다. 데모 관리자의
쓰기는 데모 데이터로 제한되며 실계정 데이터는 바꿀 수 없다.

**방금 결제한 주문이 즉시 정산서가 되지는 않는다.** 해당 거래의 정산까지 보려면
배송완료·구매확정과 정산 배치 조건을 충족해야 한다. 정산 승인과 클레임 개입은 발급 때
함께 준비되는 체험 예제로 본다.

## 확인 근거

세 역할이 같은 주문번호의 품목·수량·금액·배송 상태를 일치하게 보는지, 그리고 이 안내대로
같은 판매자의 상품을 찾아 구매·발송·관리자 확인까지 갈 수 있는지는
[TASK-0141](./tasks/M15-polish/TASK-0141-cross-role-demo-e2e.md)이 2026-09-12 운영 환경에서 검증했다.

[부분 환불 E2E](../e2e/tests/refund.spec.ts)는 판매자 계정을 먼저 만들고 그 판매자의 상품을
구매해 카드 잔액을 확인한다. 다만 상품 식별은 서버 조회로 준비하므로 이 문서의 검색 동선을
그대로 자동 실행하는 테스트는 아니다.

[가이드 테스트](../apps/shop/test/guide.spec.tsx)는 경로·렌더링·예상 시간 합계를 확인한다.
실제 사용자의 완료 시간을 증명하지는 않는다.
