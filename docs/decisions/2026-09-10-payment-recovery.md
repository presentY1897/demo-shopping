# 결제 복구 구현 결정

## D-270: 주문 단위 결제 생성과 승인 실행권

TASK-0125 사용자 승인에 따라 주문 행 잠금으로 생성 검증과 생성을 묶는다. 승인 실행권은 authorizationStartedAt으로 원자적으로 획득한다. 외부 호출 중 트랜잭션을 유지하지 않는다. 오래 남은 실행권은 대사가 UNRESOLVED로 전환 후 해소한다. CHARGE 참조는 유일하게 보장하고 기존 원장은 자동 삭제하지 않는다.

## D-271: 주문서의 보조 화면 이동과 초안

예약은 명시 취소와 TTL로 해제한다. 내부 이동과 새로고침은 해제 신호를 보내지 않는다. 배송지 ID·쿠폰·메모 초안은 예약과 함께 서버에 보존하고 배송 메모는 주문 생성 시 고정한다.
