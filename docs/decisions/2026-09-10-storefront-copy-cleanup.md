# 구매자 메인 설명 정리 — 2026-09-10

## D-269: 구매자 홈의 운영 상태 표시를 조건부 사용자 안내로 대체

사용자가 TASK-0123을 승인했다. 정상 상태의 구매자 홈에서는 API 상태·버전·가동 시간과
검색 준비 완료 표를 표시하지 않는다. 지연 시 짧은 준비 안내, 실패 시 오류와 재시도를 제공한다.
무료 플랜·경과 시간·시도 횟수·색인 설명은 구매자 홈에서 제거한다.

프리워밍과 bounded retry 정책, 동기 홈 렌더는 유지한다. 홈의 상품 섹션은 검색 준비 완료를
context로 받아 조회한다. 준비 실패를 빈 상품 목록으로 오인하지 않으며, 상품 조회 자체의
실패에도 섹션 재시도를 제공한다.

히어로는 제목, 데모 초대는 짧은 문장, 푸터는 데모 고지와 가이드 링크를 남긴다.
밀도 기능과 판매자·관리자 콘솔은 유지한다. TASK-0101·0044의 구매자 홈 표시 요구를 대체한다.

근거 및 검증: [TASK-0123](../tasks/M15-polish/TASK-0123-storefront-copy-cleanup.md).
