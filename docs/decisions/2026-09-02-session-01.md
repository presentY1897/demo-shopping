## 확정 사항

### D-001. 프로젝트 목표
취업 포트폴리오용 쇼핑몰. 데모 수준이 아니라 **실제 운영 가능한 수준**까지 구현한다.

### D-002. 역할 분리
**사용자(구매자) / 판매자(셀러) / 사이트 관리자(어드민)** 3개 역할. 각 역할별로 페이지 영역을 분리한다.

### D-003. 데모 계정
백엔드에서 **가짜 데모 계정을 즉석 발급**하여, 방문자가 가입 절차 없이 각 역할의 기능을 체험할 수 있게 한다.

### D-004. 디자인 방향
전체적으로 **미니멀·심플**. 단 상품 페이지는 **미니멀 ↔ 맥시멀 3단계**로 표현 밀도를 전환할 수 있게 한다.

### D-005. 상품 카테고리
초기 데이터는 **패션** 중심. 카테고리와 상품 속성은 코드 수정 없이 **추가·설정 가능한 구조**여야 한다.

### D-006. 레퍼런스
국내외 유명 패션 커머스를 주 레퍼런스로 하고, 기능적으로는 알리익스프레스 / 아마존 / 쿠팡을 부분 참고한다.

### D-007. 저장소 구조
`bare + worktree` 레이아웃을 사용한다.

```
shopping/
├── .bare/            # bare git 디렉터리
├── .git              # "gitdir: ./.bare"
├── main/             # main 브랜치 워크트리
└── feature-<name>/   # 기능별 워크트리 (브랜치 feature/<name>)
```

- 기능마다 브랜치와 워크트리를 분리한다.
- git identity 는 저장소 로컬 설정: `presenty1897 / presenty1897@gmail.com`

### D-008. 진행 방식
작업은 `docs/tasks/` 에 계획 문서를 먼저 작성하고, **사용자 승인 후 구현**한다.
세션에서 정해진 사항은 `docs/decisions/` 에 누적 기록한다.
