# D-273: 구매 요청의 선택적 구간 계측

TASK-0131의 운영 수초 지연을 서버 로그 접근 없이 요청 ID와 연결해 확인한다. 요청자가 `X-Checkout-Diagnostics: 1`을 명시한 구매 관련 경로에 한해 시간/횟수를 수집하고 인증된 BUYER의 응답에만 Server-Timing을 추가한다. 정적 구간 이름 외에 요청/DB/provider 데이터는 기록하지 않는다. 권한·응답 본문·과금·pool 설정은 유지한다. 진단 헤더는 CORS 허용 및 노출 목록에 명시한다. 중첩 시간과 병렬 누적 쿼리 시간을 총시간과 합산하지 않는다.

운영 trace는 소량 데모 구매에서 확인하고, 30개 이상의 반복 성능 표본은 로컬/스테이징에서 수집한다. 상세 시계 값은 성능 보장을 뜻하지 않는다. 사용자에게 표시되는 구매 화면에는 진단 정보를 추가하지 않는다.
