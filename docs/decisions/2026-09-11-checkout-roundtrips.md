# D-275: 구매 시작의 대상 조회·쓰기 왕복 축소

TASK-0132 배포 뒤 후처리는 운영 두 상품을 완료했으나 주문서/주문 생성이 브라우저의5초 제한에 걸렸다. TASK-0133에서 카탈로그 필드를 명시한 대상 SQL projection을 사용하며 전역 Prisma join 기본값은 바꾸지 않는다. 기존 Prisma select와 실제 DB 결과를 비교해 날짜/옵션/대표 이미지/정책을 보존한다.

주문서 open은 읽은 카탈로그와 방금 생성된 예약으로 응답하며, 이후 조회/실제 주문 생성은 최신 카탈로그와 쿠폰을 검증한다. 예약과 판매자 주문/항목/최초 상태 이력은 도메인 서비스 안에서 일괄 기록한다. variant 순서 잠금과 조건부 가용 재고 검사, 전체 transaction/스냅샷/쿠폰 소진 경계는 유지한다. HTTP와 transaction 제한은 늘리지 않는다.
