# 결정 이력 (Decision Log)

문서는 두 종류다.

| 문서 | 성격 | 읽는 시점 |
| --- | --- | --- |
| [**DECISIONS.md**](./DECISIONS.md) | **현재 유효한 최종 결정만** 주제별로 취합한 문서 | 지금 무엇이 정해져 있는지 알고 싶을 때 — **이것만 읽으면 된다** |
| `YYYY-MM-DD-session-NN.md` | 세션별 원본 이력. 논의 과정, 선정 근거, 폐기된 안 포함 | 왜 그렇게 정했는지 배경을 알고 싶을 때 |

## 운영 규칙

1. 세션에서 결정이 나오면 그 세션 파일에 `D-NNN` 항목으로 기록한다.
2. 이어서 `DECISIONS.md` 의 해당 항목을 **갱신**한다. (추가가 아니라 최신 상태로 덮어쓴다)
3. 결정이 번복되면 세션 파일에는 "D-NNN 대체" 로 이력을 남기고, `DECISIONS.md` 에서는 옛 내용을 지운다.
4. `DECISIONS.md` 에는 과거 이력·논의 과정을 남기지 않는다. 항상 현재 상태만 담는다.
