# shopping

취업 포트폴리오용 이커머스 서비스. 사용자 / 판매자 / 관리자 3개 역할을 지원하며,
방문자는 데모 계정을 즉시 발급받아 전체 기능을 체험할 수 있다.

## 저장소 구조

`bare + worktree` 레이아웃이다. 자세한 내용은 [CLAUDE.md](./CLAUDE.md) 참조.

```
shopping/
├── .bare/
├── main/
└── feature-<name>/
```
