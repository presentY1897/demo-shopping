# 승인 상품 제작 및 로컬 원본 반영

2026-09-10 기준 승인 상품66개, 옵션 조합151개, 고유 이미지660개를 R2 shopping-dev와 로컬 원본DB shopping에 추가했다. 원격 운영 DB는 반영하지 않았다. 원본 DB 상품은1358→1424개가 되었고 기존 회원106명/판매자60개 및 기존 상품·옵션·이미지·분류 행은 해시 비교에서 변경이 없었다. 반영 전 DB 백업을 만들고 아카이브 읽기 검사도 통과했다. 백업과 로컬 실행 결과는 해당 작업 환경에 보관한다.

이미지660장은 업로드 후 및 DB반영 전 공개 GET으로 SHA-256을 검증했다. 새 상품66개는 실제 상세 조회 서비스를 통해 이름·이미지·옵션 조합 수와 공개 갤러리 URL을 확인했다. 마지막12상품96컷은 PC·모바일 실제 상품 페이지 검사도 통과했다. 브라우저 미리보기는 별도 shopping_image_preview DB를 유지한다.

## 공개 범위 확인

업로드 전 shopping-dev의 기존 객체115개를 전부 열거하고 내용 약1.97MB를 확인했다. 상품 분류/샘플 문구의 SVG105개와 테스트 패턴·단색·1픽셀 이미지/바이트 테스트 파일10개였다. 확인 시점의 내용에서 개인정보·비공개 문서는 관찰되지 않았다. 기존 객체는 삭제하거나 변경하지 않았다. 공개 URL은 이미 활성화돼 있었으며 기존 파일의 인증 GET과 공개 GET 바이트가 일치했다.

## 생성량과 측정 한계

- 기본 상품/컬러는 개별8컷. 유니섹스 의류의 남녀 모델 프로필을 분리하는 명세는 공통 상품4컷+프로필별4컷으로 기본12컷이며 모든 변형도 같은 구성을 갖는다.
- 마지막12개 동시 요청 실행: 신규상품12개/승인96컷, 요청105회. 검수 거절7개와 세션 중단으로 결과를 잃은 요청2개를 재시도했다. 미완료 컷은 없다.
- 이 실행 중 세션 중단/재개와 실시간 시계 변경이 있어 시간·처리량 비교는 유효하지 않다. 요청의 최대 관측 겹침은12개지만 서버 내부 생성 병렬도는 알 수 없다. 토큰 사용량은 도구 응답에 없어서 추정하지 않았다.
- 기존3/6/8요청 실행의 기록상 전체 시간은 각각10상품80컷34:09,12상품96컷39:30,12상품96컷35:41이다. 상품과 검수 난이도가 달라 엄격한 성능 비교 실험은 아니다.
- 메모리 급감 시 다른 worktree의 Node 프로세스가 상위 표본에서 RSS합계 약11.1GiB를 차지했다. 공유 페이지 중복과 관측 공백이 있으므로 고유 사용량이나 이미지 서비스 메모리로 해석하지 않는다. 접근 가능한 커널 로그에서 OOM 기록은 발견하지 못했다.
